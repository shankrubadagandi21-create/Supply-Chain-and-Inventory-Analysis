

Supply Chain and Inventory Analysis

1. Project Overview

This project focuses on analyzing supply chain and inventory data using MySQL.

The objective is to help management monitor inventory levels, identify low-stock products, evaluate supplier delivery performance, and generate inventory replenishment reports.

2. Business Objectives

- Identify products with low stock.
- Calculate total inventory value.
- Analyze supplier delivery performance.
- Identify delayed supplier orders.
- Generate inventory replenishment reports.
- Analyze warehouse-wise inventory.
